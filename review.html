Reviewers

Reviewer: approves most species. Expert: also approves expert-only species (critically endangered and provisional IDs) and works the "Needs expert" queue. Admin: everything else, including blocking phones. Only you (the owner) can add, remove or change reviewers.

Add a reviewer

Enter their email and choose a role. If they don't have an account yet, one is made with a temporary password for you to pass on; they choose their own password the first time they sign in. If they already have an account, they get access straight away.

Blocked phones

Blocked phones can't upload. Block one from any record it sent (Block this phone). That also deletes everything it sent that wasn't approved.

Add reference photos

Seed the identifier with photos whose species you're sure of (your own, or ones you have permission to use). Every record you approve is added to the library automatically too. To train the identifier with a submitted photo without publishing it in Records, use Reference only in the queue.

Batch import

Add photos for many species at once. Start each file name with the species ID and two underscores, e.g. tiger__seatizens.jpg or great-hammerhead__2.jpg. Files whose name doesn't match a species are skipped.
