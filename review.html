Add reference photos

          
Seed the identifier with photos whose species you're sure of (your own, or ones you have permission to use). Every record you approve is added to the library automatically too. To train the identifier with a submitted photo without publishing it in Records, use Reference only in the queue.

          

            
            
            
          

          
          

        

        

          
Batch import

          
Add photos for many species at once. Start each file name with the species ID and two underscores, e.g. tiger__seatizens.jpg or great-hammerhead__2.jpg. Files whose name doesn't match a species are skipped.
